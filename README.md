# karthikrocksta.github.io

Karthik Krishna Kumar - Professional Portfolio

A high-performance, responsive portfolio website built for a Solutions Architect. This project features a modern "Glassmorphism" UI, a simulated AI assistant, and a direct WhatsApp integration for lead generation.

🚀 Features

Modern UI/UX: Built with Tailwind CSS, featuring smooth animations and a responsive design that works on mobile, tablet, and desktop.

AI Chatbot Simulation: An interactive assistant that answers common questions about my professional background (NPST, Canara ai1, Tech Stack).

WhatsApp Integration: A custom contact form that formats messages and opens them directly in WhatsApp for immediate communication.

Optimized Performance: Removed WebGL dependencies in favor of lightweight CSS animations to ensure 100% compatibility across all browsers.

📂 Project Structure

index.html: The main entry point containing all HTML, CSS, and JavaScript.

profile.png: My profile photo in the root directory. This is used for the site favicon, the hero section, and the AI bot avatar.

📱 Contact Integration

The "Let's Connect" and "Hire ME" buttons use the WhatsApp Click-to-Chat API. It pre-fills a structured message including the sender's name and purpose of inquiry.
